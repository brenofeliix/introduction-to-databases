# 5. WHERE

Utilize `WHERE` para filtrar registros.

Exemplo:

```sql
SELECT *
FROM produto
WHERE preco > 100;
```

Operadores comuns:

```text
=   igual
<>  diferente
>   maior que
<   menor que
>=  maior ou igual
<=  menor ou igual
```

Também podem ser utilizados:

```sql
AND
OR
LIKE
BETWEEN
IN
IS NULL
IS NOT NULL
```

Exemplo:

```sql
SELECT *
FROM produto
WHERE preco > 100
  AND estoque > 0;
```

## Consulta obrigatória com WHERE

### Pergunta respondida

> Quais unidades têm estoque baixo de determinada vacina?

### SQL

```sql
SELECT id_unidade, nome, quantidade 
FROM estoque_item 
WHERE tipo = 'VACINA' AND quantidade < 50;

```

### Explique o filtro

> O filtro WHERE utiliza o operador AND para garantir que o item seja especificamente uma 'VACINA' e que o seu nível de estoque seja crítico (menor que 50).

# 6. ORDER BY

Ordenação crescente:

```sql
SELECT *
FROM produto
ORDER BY preco ASC;
```

Ordenação decrescente:

```sql
SELECT *
FROM produto
ORDER BY preco DESC;
```

Por mais de uma coluna:

```sql
SELECT *
FROM produto
ORDER BY categoria ASC, preco DESC;
```

## Consulta obrigatória com ORDER BY

### Pergunta respondida

> Quais pacientes têm atendimentos agendados para os próximos dias?

```sql
SELECT id_paciente, data_hora, tipo_atendimento 
FROM atendimento
```

# 9. GROUP BY

`GROUP BY` permite agrupar registros.

Exemplo:

```sql
SELECT categoria_id,
       COUNT(*) AS quantidade
FROM produto
GROUP BY categoria_id;
```

Outro exemplo:

```sql
SELECT status,
       COUNT(*) AS quantidade
FROM pedido
GROUP BY status;
```

## Consulta obrigatória com GROUP BY

### Pergunta respondida

> Qual o número de óbitos registrados por unidade?

### SQL

```sql
SELECT unidade_responsavel, COUNT(*) AS total_obitos 
FROM obito 
GROUP BY unidade_responsavel;

```

### Explique o agrupamento

> Agrupa os registros da tabela obito com base no ID da unidade_responsavel e conta quantos óbitos ocorreram em cada uma.
---

# 10. HAVING

`WHERE` filtra registros antes do agrupamento.

`HAVING` filtra os grupos após o `GROUP BY`.

Exemplo:

```sql
SELECT categoria_id,
       COUNT(*) AS quantidade
FROM produto
GROUP BY categoria_id
HAVING COUNT(*) > 5;
```

## Consulta obrigatória com HAVING

### Pergunta respondida

> Quantos atendimentos cada profissional realizou no mês (filtrando apenas os que realizaram 2 ou mais)?

### SQL

```sql
SELECT id_profissional, COUNT(*) AS total_atendimentos 
FROM atendimento 
WHERE status = 'REALIZADO' 
GROUP BY id_profissional 
HAVING COUNT(*) >= 2;

```

### Por que HAVING foi necessário?

> O WHERE filtrou apenas os atendimentos "REALIZADOS", mas o HAVING foi necessário para filtrar o resultado da agregação (COUNT), mostrando apenas profissionais com 2 ou mais atendimentos.

# 11. Expressões SQL

É possível realizar cálculos em consultas.

Exemplo:

```sql
SELECT nome,
       preco,
       preco * 0.90 AS preco_com_desconto
FROM produto;
```

Outro exemplo:

```sql
SELECT quantidade,
       valor_unitario,
       quantidade * valor_unitario AS subtotal
FROM item_pedido;
```

## Consulta com expressão

```sql
SELECT nome, quantidade, (quantidade * 0.10) AS meta_reposicao 
FROM estoque_item;

```

### Explique o cálculo

> Calcula uma margem de segurança de 10% baseada no estoque atual para prever uma meta mínima de reposição na próxima compra.

Caso não seja aplicável ao domínio, justifique.

# 14. Modelo genérico para adaptar

**Não entregue este código sem adaptação.**

```sql
USE nome_do_banco;

-- SELECT básico
SELECT *
FROM tabela_a;

-- Colunas específicas
SELECT campo_a1, campo_a2
FROM tabela_a;

-- WHERE
SELECT *
FROM tabela_a
WHERE campo_numerico > 10;

-- Duas condições
SELECT *
FROM tabela_a
WHERE campo_numerico > 10
  AND campo_status = 'ATIVO';

-- ORDER BY
SELECT *
FROM tabela_a
ORDER BY campo_a1 ASC;

-- COUNT
SELECT COUNT(*) AS total_registros
FROM tabela_a;

-- SUM
SELECT SUM(campo_numerico) AS total
FROM tabela_a;

-- AVG
SELECT AVG(campo_numerico) AS media
FROM tabela_a;

-- MIN / MAX
SELECT MIN(campo_numerico) AS menor_valor,
       MAX(campo_numerico) AS maior_valor
FROM tabela_a;

-- GROUP BY
SELECT campo_categoria,
       COUNT(*) AS quantidade
FROM tabela_a
GROUP BY campo_categoria;

-- HAVING
SELECT campo_categoria,
       COUNT(*) AS quantidade
FROM tabela_a
GROUP BY campo_categoria
HAVING COUNT(*) > 1;

-- Expressão
SELECT campo_a1,
       campo_numerico,
       campo_numerico * 1.10 AS valor_calculado
FROM tabela_a;
```

> Substitua `nome_do_banco`, `tabela_a`, `campo_a1`, `campo_numerico`, `campo_categoria` e demais nomes genéricos pelos nomes reais do seu projeto.

# 18. Consulta mais útil

### Pergunta

> Quais pacientes têm atendimentos agendados para os próximos dias?

### SQL

```sql
SELECT id_paciente, id_unidade, data_hora, tipo_atendimento 
FROM atendimento 
WHERE status = 'AGENDADO' AND data_hora >= '2026-10-26'
ORDER BY data_hora ASC;

```

### Por que ela é útil?

> Ela permite que a recepção das unidades de saúde saiba exatamente quem será atendido nos próximos dias e em qual ordem cronológica, essencial para o funcionamento diário da clínica.

# 19. Consulta mais complexa

### Pergunta

> Qual o tipo de atendimento mais frequente por unidade?

### SQL

```sql
SELECT id_unidade, tipo_atendimento, COUNT(*) AS frequencia 
FROM atendimento 
GROUP BY id_unidade, tipo_atendimento 
ORDER BY id_unidade, frequencia DESC;

```

### Qual foi a dificuldade?

> Foi necessário agrupar por duas colunas diferentes (id_unidade e tipo_atendimento) simultaneamente, e ordenar pelo resultado da contagem decrescente para ver os mais frequentes no topo.
